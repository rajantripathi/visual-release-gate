# Independent reviewer instructions

Review all 24 cases without seeing model outputs or the other reviewer's work.
Use only the guide, rules, approved references, current brief, and target image.

For every case, choose one primary verdict:

- `ship`: decision-critical checks visibly pass.
- `reject`: a visible critical or major defect blocks release.
- `human_review`: visual or source ambiguity prevents a safe decision.
- `unsupported`: release depends on absent authority such as rights, consent, or legal approval.

Copy `reviewer_template.jsonl` to a private working file, replace every
`__FILL__` field, and return the completed file to the project owner. Do not
discuss cases with the other reviewer until both files are frozen. Reviewer
names are not published without explicit consent.
